# Atithi Premium Website Demo

A single-file responsive website concept for **Atithi Sweets Bakery Chaat & Mart, BCS, New Shimla**.

## Design direction
- Editorial local-food aesthetic instead of the usual red/gold restaurant template.
- Pine green + warm cream + terracotta palette.
- Large serif display typography paired with clean sans-serif UI.
- Full-bleed hero, category tiles, product storytelling, occasions, social proof, and a clear location CTA.
- Mobile-first spacing and large tap targets.

- Location: BCS Market / New Shimla, Shimla, Himachal Pradesh

## Run
Open `index.html` in any modern browser or upload the file to GitHub Pages, Netlify or Vercel.
